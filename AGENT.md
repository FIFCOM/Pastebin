# Material Bin Agent Instructions

## Version Management Skill

Use `$manage-materialbin-version` for every task involving product versions, ordinary commit
version bumps, Git hook setup or diagnosis, manual minor/major releases, `vX.Y.Z` tags, GHCR
release labels, version repair, or version-preserving amend operations.

Skill source:
[.agents/skills/manage-materialbin-version/SKILL.md](.agents/skills/manage-materialbin-version/SKILL.md)

Do not duplicate version procedures here. Follow the skill and treat the root `VERSION` file as
the repository's version source.
